MONUNHH: Every question goes through lib/engine/tiers.ts in this order. Guardrails first, so an out-of-scope question never reaches a model. Then curated answers, served word for word. Then hybrid retrieval: BM25 keyword search plus dense search, fused with reciprocal rank fusion and reranked. A confidence gate runs before generation, so weak retrieval declines instead of producing a fluent wrong answer. The model writes only from the sources, then a verification gate can still withhold the answer, output moderation checks it, and citations are attached. The order is the safety design.
