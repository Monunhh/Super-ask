Unit testing · One test up close

Catching an invented fee before a citizen sees it

// tests/engine/verify.test.ts

it("catches an invented fee", () => {

  const result = verify(

    "The fee is 45,000 riel.",

    ["X-1"],

    [source("X-1", "A fee of 30,000 riel

        applies on renewal.")],

    ["X-1"],

  );

  expect(result.passed).toBe(false);

  expect(result.unsupported).toContain("45000");

});

BUNKHEANG: Here is one real test from our repo, so you can see the pattern every test follows: arrange, act, assert. We arrange an answer that says the fee is 45,000 riel while the cited source says 30,000. We act by running the verification gate. We assert that it fails and names 45000 as the unsupported number. An invented fee reaching a citizen is exactly the harm SuperAsk exists to prevent, so this is one of the most important tests we have. The same file also checks the reverse direction, so a correct answer is not blocked: for example, 30 days in the answer matches thirty days in the source, and Khmer digits match Arabic digits.
