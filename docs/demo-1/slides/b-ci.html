BUNKHEANG: This is how tests protect our main branch. You write code and tests on a branch, run npm test locally, then push and open a pull request. GitHub Actions then runs two jobs in parallel. The check job installs, typechecks, runs every test with coverage and fails under 85 percent, builds the production app, runs the retrieval evaluation, and runs four answer-gate checks. The secrets-scan job makes sure no API key or .env file was committed. Green means we can merge to main; red blocks the merge until it is fixed. A real example: our redesign pull request this week passed both jobs in about a minute and was merged. And on 6 October, CI went red on a rebrand commit; we fixed it and it was green six minutes later, before it could break anything for users. Over to Heejae.
