MONUNHH: The app is Next.js 15 with React 19 and TypeScript, styled with Tailwind, hosted on Vercel, with a Telegram webhook. Only the server route /api/ask talks to a model, so no credential ever reaches the browser. All model-specific code is in lib/llm, behind one interface: today we use SEA-LION from AI Singapore, and moving to a self-hosted Qwen model in Cambodia is one environment variable. If a provider fails, we degrade to extracting text from the sources rather than breaking.
