BUNKHEANG: This is how our unit tests map onto the answer pipeline Monunhh showed. Screening has 141 tests, mostly the guardrails, because a refusal rule that silently stops working is the most dangerous bug we could have. Retrieval has 148, including Khmer normalisation and romanised Khmer, since a Khmer question typed differently must still find the same source. Deciding which tier answers has 86, generation has 96 covering prompts and every model provider, verification has 21, and citations plus audit logging have 74. Another 44 cover chat history and the crawler. Each number is the exact count from the test runner.
