# SuperAsk.AI — Demo 1 slides

The Demo 1 presentation (CSCI 441): 5 slides, as the Demo 1 requirements allow
(overview, roadmap, the live-demo plan, and the plan for the rest of the
semester). The use cases themselves are shown live, each by its owner.

## Online and PDF

- **View / present online (anyone, no login):**
  https://htmlpreview.github.io/?https://github.com/Monunhh/Super-ask/blob/main/docs/demo-1/slides/index.html
- **Download PDF (5 slides):**
  https://github.com/Monunhh/Super-ask/raw/main/docs/demo-1/5_documentation/presentation_slides.pdf
  — or the **Download PDF** button / `D` key while presenting.

Both follow `main`: push slide changes (and the rebuilt `index.html` / PDF)
and the links show the new version.

## Present

Double-click **`index.html`** (or `open docs/demo-1/slides/index.html`). It opens straight
into presentation mode — no install, no server. Fonts load from Google Fonts,
so be online once; offline the text falls back to Arial.

| Key | Action |
|---|---|
| `→` `Space` / `←` `Backspace` | Next / previous slide (or click right / left side, or swipe) |
| `F` | Full screen |
| `S` | **Presenter view** in a second window: current + next slide, speaker notes, timer, clock — stays in sync |
| `N` | Speaker notes over the slide |
| `G` | Overview of all slides — click one to jump |
| `7` `Enter` | Jump to slide 7 |
| `B` | Black screen |
| `D` | Download the PDF |
| `?` | Shortcut list |
| `Ctrl/⌘` `P` | Print or save as PDF, one slide per page |

The address bar keeps the slide number (`index.html#11`), so a reload stays
on the same slide. With a projector: open presenter view (`S`), drag the main
window to the projector and press `F`.

## Edit

Change a slide file (or `deck.json` for order), then rebuild:

```
python3 docs/demo-1/slides/build.py          # rebuild index.html
python3 docs/demo-1/slides/build.py --pdf    # also rebuild ../5_documentation/presentation_slides.pdf (needs Chrome)
```

`index.html` is generated — don't edit it by hand.

**Present / export:** the editable deck is the claude.ai Slides artifact this
folder was copied from. From its page, *Share › Export* downloads PowerPoint
(`.pptx`, which imports into Canva) or PDF.

## Files

| Path | What it is |
|---|---|
| `<id>.html` | One slide each (the 5 files listed below): a single 1920×1080 `<section>` with inline styles. The `<aside>` at the end is the speaker notes, including the exact demo questions. |
| `backup/` | The earlier 20-slide deck (architecture, unit tests, CI, integration tests, evaluation, data). Not in the presentation; keep it open for questions. |
| `deck.json` | Deck index: title, slide order (`order`), sections and fonts (Space Grotesk + Inter, Google Fonts). |
| `index.html` | The presentation: every slide plus a small player (navigation, presenter view, overview, print). Generated by `build.py`. |
| `build.py` | Rebuilds `index.html` from `deck.json` and the slide files. Python 3, standard library only. |

`<x-icon>` and `<x-shape>` are tags of the Slides deck format; `build.py`
turns them into real line icons and arrows for the browser.

**Do not use on stage:** the landing-page buttons *Passport application*,
*Business registration*, *Vehicle registration* (English), *Trademark
registration*, or *Driving licence renewal* in Khmer; questions about
passports, business registration or land titles; the crawler on SRC-034
(mpwt.gov.kh, too slow). These topics are not in the knowledge base, and
retrieval currently returns an unrelated passage instead of declining.

Telegram was not tested from here: send the UC-7 question to @superask168_bot
before the slot.
